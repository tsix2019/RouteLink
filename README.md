<h1 align="center">RouteLink</h1>

<p align="center"><b>中文</b> | <a href="README.en.md">English</a></p>

> 🚧 **开发中**：第一个里程碑（M1）正在开发，功能、截图和安装包会陆续补上。

RouteLink 是一款管理 OpenWrt 路由器的手机 App，支持 iOS 和 Android，界面有中文和英文。

- **界面**：iOS 26 液态玻璃风格。iOS 上用系统原生的玻璃效果；Android 上用背景模糊仿出同样的样子。
- **自动发现**：自动扫描局域网里的 OpenWrt 设备，旁路由也能找到。
- **多路由器**：支持添加多台路由器，随时切换。
- **功能范围**：对标现有开源 OpenWrt App 的全部功能。高风险操作（刷机、恢复出厂等）都有分级风险提示。
- **隐私**：不收集任何数据。App 只和你的路由器通信。
